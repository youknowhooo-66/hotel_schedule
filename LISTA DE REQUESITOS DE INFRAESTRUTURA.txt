Lista de requisitos de infraestrutura do projeto Hotel Schedule:

1. Tempo de Execução (Runtime): Node.js (v18 ou superior).
2. Banco de Dados: PostgreSQL (via Prisma ORM) para persistência de dados hoteleiros.
3. Conteinerização: Docker e Docker Compose para isolamento do backend e banco de dados.
4. Segurança de Ambiente: Gerenciamento de segredos e chaves JWT via arquivos .env e utilitário env.js.
5. Qualidade de Código: Suíte de testes automatizados com Jest e Supertest para validação de APIs.
6. Controle de Versão: Git para rastreabilidade de código.
7. Disponibilidade: Estrutura preparada para integração com pipelines de CI/CD (GitHub Actions/GitLab CI).
8. Auditoria: Sistema de logs de auditoria (Audit Log) integrado ao banco de dados para rastrear ações de usuários.
9. Servidor Web: Express.js com políticas de CORS configuradas para integração com o Frontend (Vite).
